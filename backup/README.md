# 挖矿游戏

一款基于HTML5和JavaScript开发的网页挖矿游戏，包含丰富的游戏系统和玩法。

## 游戏功能

### 核心系统
- **玩家系统**：等级、经验值、金币管理
- **工具系统**：采矿锄、矿车、头灯的升级和使用
- **矿物系统**：多种矿物的采集和管理
- **背包系统**：物品存储、出售、拆解、过滤和整理
- **制作系统**：制作工具、熔炉、背包扩充等
- **熔炉系统**：融石、制作合金
- **加工台系统**：高级物品制作（需要解锁）
- **商店系统**：购买物品和图纸
- **任务系统**：完成任务获得奖励
- **存档系统**：多存档位管理、数据导出导入

### 游戏玩法

1. **开始挖矿**：点击矿物列表中的矿物进行采集
2. **升级工具**：使用金币和材料升级采矿锄、矿车和头灯
3. **管理背包**：出售不需要的物品，整理背包空间
4. **制作物品**：使用熔炉制作合金，制作矿车、头灯等工具
5. **扩充背包**：制作扩充背包增加存储容量
6. **完成任务**：完成游戏任务获得额外奖励
7. **解锁内容**：随着等级提升解锁新的矿物和功能
8. **保存游戏**：定期保存游戏进度，避免数据丢失

## 游戏特色

- **自动挖矿**：制作矿车后可以自动挖矿
- **自动出售**：设置物品过滤，自动出售多余物品
- **挂机系统**：记录挂机时间和获得的资源
- **多存档**：支持多个存档位，方便管理不同游戏进度
- **数据导入导出**：支持游戏数据的导出和导入，方便备份和转移
- **丰富的物品**：多种矿物、布料和制作物品
- **技能升级**：工具可以通过使用获得经验并升级

## 如何开始

1. 下载或克隆本项目到本地
2. 双击 `index.html` 文件在浏览器中打开游戏
3. 开始你的挖矿之旅！

## 游戏操作

### 基本操作
- **点击矿物**：开始采集对应矿物
- **保存游戏**：点击"保存游戏"按钮保存当前进度
- **加载游戏**：点击"加载游戏"按钮加载已保存的进度
- **导出数据**：点击"导出数据"按钮导出游戏数据
- **导入数据**：点击"导入数据"按钮导入之前导出的游戏数据

### 工具操作
- **升级采矿锄**：点击采矿锄旁边的"升级工具"按钮
- **制作/使用矿车**：点击"制作矿车"按钮制作矿车，制作完成后可以开始使用
- **制作/使用头灯**：点击"制作头灯"按钮制作头灯，制作完成后可以开始使用
- **添加燃料**：为矿车和头灯添加燃料以维持其运行

### 背包操作
- **出售物品**：点击"出售物品"按钮，选择要出售的物品和数量
- **拆解物品**：点击"拆解物品"按钮，选择要拆解的物品和数量
- **自动出售**：点击"自动出售"按钮，设置物品过滤规则
- **整理背包**：点击"整理背包"按钮自动整理背包物品

### 制作操作
- **融石**：在熔炉中选择融石配方，制作石灰或煤炭
- **制作合金**：在熔炉中选择合金配方，制作各种合金
- **制作工具**：在制作系统中制作矿车、头灯等工具
- **制作扩充背包**：在制作系统中制作扩充背包，增加背包容量
- **制作熔炉**：在制作系统中制作熔炉，用于融石和制作合金

## 游戏数据

游戏数据存储在浏览器的本地存储中，通过"导出数据"按钮可以将数据导出为JSON格式，通过"导入数据"按钮可以导入之前导出的数据。
