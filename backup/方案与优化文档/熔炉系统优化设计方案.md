# 熔炉系统优化设计方案

## 一、核心功能优化设计

### 1. 自动制作系统

#### 1.1 功能描述
自动制作系统允许玩家设置熔炉自动制作指定物品，无需手动操作，提高游戏效率。

#### 1.2 数据结构设计

```javascript
// 在gameData.furnace中添加自动制作相关字段
furnace: {
    // 原有字段...
    autoCraft: {
        enabled: false,              // 是否启用自动制作
        recipe: null,                // 当前自动制作的配方
        amount: 0,                   // 自动制作的数量（0表示无限）
        interval: 1000,              // 制作间隔（毫秒）
        currentCount: 0,             // 当前已制作数量
        nextCraftTime: 0             // 下次制作时间
    }
}
```

#### 1.3 功能流程
1. 玩家在熔炉界面选择自动制作选项
2. 选择要制作的配方和数量
3. 设置制作间隔
4. 点击开始自动制作
5. 熔炉每隔指定间隔自动消耗材料制作物品
6. 达到指定数量或材料不足时停止

### 3. 燃料系统优化

#### 3.1 功能描述
优化燃料系统，设计基于熔炉等级和物品类型的燃料消耗公式，添加燃料质量概念。

#### 3.2 燃料类型与属性

| 燃料类型 | 热值 | 燃烧时间 | 特殊效果 |
|---------|------|---------|---------|
| 煤矿 | 1 | 10秒 | 基础燃料 |
| 煤炭 | 2 | 20秒 | 燃烧稳定 |
| 高级燃料 | 5 | 50秒 | 燃烧效率+20% |
| 合成燃料 | 10 | 100秒 | 燃烧效率+50% |

#### 3.3 燃料消耗公式

```
燃料消耗 = 基础燃料消耗 × 物品复杂度系数 × 熔炉等级系数

物品复杂度系数：
- 基础物品：1.0
- 中级物品：1.5
- 高级物品：2.0
- 合金：3.0

熔炉等级系数：
- 等级1：1.0
- 等级2：0.9
- 等级3：0.8
- 等级4：0.7
- 等级5+：0.6
```

#### 3.4 关键函数设计

```javascript
// 获取燃料消耗
function calculateFuelConsumption(itemType, amount) {
    const baseCost = getBaseFuelCost(itemType);
    const complexityFactor = getComplexityFactor(itemType);
    const levelFactor = getFurnaceLevelFactor();
    return Math.ceil(baseCost * complexityFactor * levelFactor * amount);
}

// 获取熔炉等级系数
function getFurnaceLevelFactor() {
    const level = gameData.furnace.level;
    if (level >= 5) return 0.6;
    return 1.0 - (level - 1) * 0.1;
}
```

```javascript
// 使用setTimeout处理长时间操作
function batchCraft(recipe, amount) {
    let remaining = amount;
    
    function craftNext() {
        if (remaining <= 0) return;
        
        // 执行单次制作
        craftItem(recipe, 1);
        remaining--;
        
        // 继续下一次制作
        setTimeout(craftNext, 100); // 100ms间隔，避免卡顿
    }
    
    craftNext();
}
```

### 2. 数据缓存机制

```javascript
// 缓存常用计算结果
const furnaceCache = {
    fuelConsumption: {},
    efficiency: 0,
    cacheTime: 0
};

// 获取燃料消耗（带缓存）
function getFuelConsumption(itemType, amount) {
    const cacheKey = `${itemType}_${amount}`;
    const now = Date.now();
    
    // 缓存有效期5秒
    if (furnaceCache.fuelConsumption[cacheKey] && now - furnaceCache.cacheTime < 5000) {
        return furnaceCache.fuelConsumption[cacheKey];
    }
    
    // 计算并缓存结果
    const result = calculateFuelConsumption(itemType, amount);
    furnaceCache.fuelConsumption[cacheKey] = result;
    furnaceCache.cacheTime = now;
    
    return result;
}
```
