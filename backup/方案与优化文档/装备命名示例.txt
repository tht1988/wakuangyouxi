# 装备命名示例

## 普通装备
直接使用基础名字：
- 短刀
- 重剑
- 长剑
- 双手剑
- 细剑
- 战矛

## 魔法装备
蓝色字体前缀名+后缀名+基础名：
- 微小之带刃的长剑
- 小幅之开刃的短刀
- 增加之锐利的重剑
- 提升之锋利的双手剑
- 额外之穿刺的细剑

## 装备命名规则说明
1. **普通装备**：直接使用基础名字
2. **魔法装备**：前缀名+后缀名+基础名（蓝色字体）
3. **稀有装备**：
   - 随机从词缀中提取两个核心属性或效果，组合成独特名称
   - 显示装备类型和基础名称
   - 需求等级根据词缀等级和基础装备等级计算
   - 显示速度类型和伤害类型
   - 显示基础伤害范围
   - 显示所有词缀效果

## 词缀组合示例
- 巨力之 + 雷暴之 = 雷毁
- 带刺的 + 致命的 = 刺命
- 毁灭的 + 闪电的 = 电毁
- 碎裂的 + 冰冻的 = 冰裂
- 粉碎的 + 火焰的 = 火碎
- 穿刺的 + 毒素的 = 毒穿
- 锋利的 + 迅捷的 = 迅锋
- 锐利的 + 精准的 = 精锐

这些命名规则和示例可以用于游戏中自动生成装备名称，根据装备的稀有度和词缀属性生成独特且有意义的装备名称。


更高稀有度的装备可以根据属性加入特殊人名比如谢逊的屠龙刀，雷神索尔的巨锤等等
