## 3. 刷新机制

### 自动刷新

| 属性 | 描述 |
|------|------|
| 刷新时间 | 3分钟（180秒） |
| 触发条件 | 倒计时结束时自动调用 `refreshShopItems()` |
| 函数调用 | `refreshShopItems()` |
| 效果 | 重置物品列表，更新刷新时间 `lastRefresh` |

### 手动刷新

| 属性 | 描述 |
|------|------|
| 消耗 | 1000金币 |
| 触发方式 | 点击手动刷新按钮 |
| 函数调用 | `manualRefreshShop()` → `refreshShopItems(true)` |
| 特殊效果 | 1. 添加旅行背包到物品池（如果上次没出现）<br>2. 不重置自动刷新时间<br>3. 更新旅行背包出现状态 |

### 免费刷新

| 属性 | 描述 |
|------|------|
| 获取方式 | 1级商店（等级1）后，每10分钟获得1次免费刷新 |
| 上限 | 最多50次 |
| 函数调用 | `refreshShopItems(false, true)` |
| 限制 | 1. 不添加优惠商品<br>2. 不参与随机打折或涨价<br>3. 不重置自动刷新时间 |

## 4. 刷新相关函数

| 函数名称 | 功能描述 | 参数 | 调用位置 |
|---------|---------|------|---------|
| `refreshShopItems(isManualRefresh, isFreeRefresh)` | 生成新的商店物品列表 | isManualRefresh: 是否手动刷新<br>isFreeRefresh: 是否免费刷新 | 自动刷新倒计时结束时<br>手动刷新按钮点击时<br>免费刷新按钮点击时 |
| `updateShopCountdown()` | 更新商店倒计时和免费刷新次数 | 无 | 游戏主循环中调用 |
| `manualRefreshShop()` | 处理手动刷新逻辑 | 无 | 手动刷新按钮点击事件 |
| `freeRefreshShop()` | 处理免费刷新逻辑 | 无 | 免费刷新按钮点击事件 |

## 5. 商品生成逻辑

1. **物品数量**：每次刷新生成3-5个物品
2. **图纸过滤**：已解锁的图纸不会再次出现
3. **旅行背包限制**：不会连续出现2次
4. **矿物过滤**：只添加已解锁的石矿和煤矿
5. **优惠商品**：非免费刷新时10%几率添加，免费刷新时不添加
6. **合金添加**：玩家达到等级要求后添加对应合金
7. **随机价格调整**：非优惠产品有10%几率打折（50%）或涨价（50%），旅行背包除外
8. **谨慎矿工效果**：有该效果时只选择打折物品，无打折物品时自动创建打折物品
9. **3级商店功能**：<br>   - 可设置"我需要的物品"，该物品出现概率增加<br>   - 需求物品价格为300%<br>   - 自动采购功能
